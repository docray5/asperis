class View(builtins.object)
    View(model)
 
View class from the MVC pattern.
Responsible only for drawing objects.
It does have a reference to the model object, but It does not
modify the model in any way.
I am aware that an Observer pattern would be better to
implement here, in order to decouple.
I did try to implement one, but in the middle I noticed it's
just not worth for such simple project.
It also gets the currently selected scene from the model
and renders appropriately.
